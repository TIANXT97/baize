## 摘要（Executive Summary）

白泽（Bai Ze）自 v1.5.1 迈向 **v1.5.2「天禄·轻羽」**，在巩固了“四道认知防线 + 物理落盘 + Jev/Laya 双端决策门控”的基石之上，攻克了长生命周期 Agent 记忆库数据增长（突破 6.6 万条事实、3.2 万条向量）带来的 CPython 堆内存膨胀与页缓存沉淀痛点。

本版本完成了底层的**游标流式分块（fetchmany streaming）与全局页缓存硬锁控**微创手术：
1. **向量检索游标流式化（内存削减 46%）**：废止全量 `fetchall()` 反序列化 3.2 万个 Python 字典对象的暴饮暴食行为，改为 `cur.fetchmany(2000)` 游标分批流式消费。每批仅保留轻量标量元组并即时释放，在 100% 保持数学召回完全一致的前提下，日常物理常驻内存（RSS）稳定在 **75MB ~ 80MB**；
2. **SQLite 页缓存与 mmap 硬约束**：全局连接统一焊死 `PRAGMA cache_size = -1000`（单连接上限 1MB）与 `PRAGMA mmap_size = 0`，封死 Linux 脏页沉淀后路；
3. **即时垃圾泄洪（malloc_trim）**：检索结束瞬间显式调用 `malloc_trim(0)` 归还瞬态堆碎片，压制 CPython 内存水位线；
4. **极限对抗验证通过**：经受住 12 线程混合并发读写（0 次死锁）与连续 50 轮全库 3.2 万向量密集检索轰炸，高压平台稳定回落，无任何内存泄漏。

## 一、 系统定位与架构全景

### 1.1 核心设计哲学
1. **轻量自托管铁律**：纯血 Debian 13 环境，零外部臃肿依赖（无 JVM、无分布式 etcd/MinIO/Pulsar），单进程原生 Python + SQLite WAL，常驻端口 `8767`，日常常驻内存仅 **75MB ~ 80MB**，毫秒级响应。
2. **进门过滤废话，出门智能召回**：
   - **写入门神**：TypeSafe Jev 前置拦截纯闲聊、无持久价值的过渡句，保护知识库纯度；
   - **召回门神**：Jev 智能决策用户意图，配合白名单直通，实现“该想时心领神会，不该想时绝不添乱”。
3. **流式消费与严格有界（Bounded & Streaming）**：绝不将全量大表或批量对象常驻内存，所有高频数据处理均以 2000 为步长流式迭代，算完即放。
4. **结构不可达 > 提示词约定**：绝不依赖 LLM “请不要提取推测” 的软性约定，在输入解析层直接按角色机械盖戳，非用户亲陈事实在代码层物理剥夺进入 CoreMemory 的权限。
5. **耐久性至上（Durability First）**：应用层 WAL 必须经过 `f.flush()` 与 `os.fsync()` 穿透内核 Page Cache，落盘才算数。

## 二、 核心机制与技术实现（v1.5.2 关键升级）

### 2.1 游标流式消费与页缓存硬锁（v1.5.2 瘦身核心）
- **向量检索游标流式消费（Streaming Recall）**：
  - 在 `modules/hybrid_recall.py` 的 `_vector_search_i8` 中，废止一次性 `fetchall()`，改为 `cur.fetchmany(2000)` 分块拉取。
  - 每批过滤坏 blob 后立即转为连续 numpy 矩阵计算余弦，仅收集轻量 `(mem_id, score)` 标量；
  - 循环中显式 `del batch` 释放原始对象，循环结束后一次性拼接做 `np.argpartition` 取 Top-k。
  - 检索返回前触发 `ctypes.CDLL("libc.so.6").malloc_trim(0)`，压制堆内存碎片。
- **SQLite 缓存与内存映射硬约束**：
  - 全局连接统一注入 `PRAGMA cache_size = -1000;`（单连接页缓存限制 1MB）与 `PRAGMA mmap_size = 0;`（关闭 mmap），杜绝内核脏页常驻。

### 2.2 双端智能门控体系（Jev Gate & Memory Gate）
- **写入端前置快筛（Ingest Fast Filter）**：
  - 调用 Jev `systemone` 判别模型，评估文本长期记忆价值（`threshold=0.25`）。判定为 `ephemeral` 闲聊直接返回空，削减 70% Token 消耗。WAL 重放路径强制绕过门控。
- **召回端智能门神（Search Smart Gate）**：
  - 纠正信号与显式口令 0ms 白名单直通；Jev 语义意图判定（`search_threshold=0.35`）；HF Laya 弹性兜底与正则 Fail-open 容灾。

### 2.3 四道认知防线（Cognitive Defense）
- **Origin 身份硬隔离**：非用户亲陈事实物理禁止同步进 `user_profile`；
- **极性反转取代**：否定词翻转直接判定 `replaces`（置信度 0.85），破除 Jaccard 线性稀释；
- **被否决事实墓碑（rejected_values）**：废弃事实 SHA-256 铸入墓碑，换 ID 或微调语序绝对拦截；
- **生肉回灌硬熔断**：提取返回空坚决不落盘，超长文本与动作描写强制拒签。

### 2.4 工业级排他存储事务（P0 坚固内核）
- `get_db(write=True)` 执行 **`BEGIN IMMEDIATE`** 提前抢占写锁，消灭读升写死锁；
- `wal.py` 写入后执行 `os.fsync()` 穿透内核物理刷盘。
