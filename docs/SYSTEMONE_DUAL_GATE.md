# 白泽 System One 旁路门控双子星架构说明书 (OpenJev + Drex v2.0)

## 1. 架构背景
白泽记忆中枢采用两级记忆过滤流水线：
前置决策门控（System One Gate）负责在 500~700ms 内对传入消息完成两极概率打分，将日常口水、闲聊吐槽拦在昂贵的提取大模型（LLM Extractor）之外。

原有单点门控存在两大约束：
1. **单点风险**：单一供应商网关若遇超时或波动，降级直接退化为弱正则兜底；
2. **跨语言语义理解偏差**：原 JevGate 使用纯英文提示词，在面对中文复杂语境、混合长句或特定专业事实时存在语言失配与置信度摇摆。

---

## 2. 双子星主备异构设计 (Dual-Gate Architecture)

白泽 v1.5.3-baize 引入主备无缝双子星架构：

```text
               ┌────────────────────────┐
               │    用户输入 / 搜索召回   │
               └───────────┬────────────┘
                           │
                           ▼
               ┌────────────────────────┐
               │  前置黑话与短文本白名单  │ ──(命中)──► 放行入库 (Fast-Path)
               └───────────┬────────────┘
                           │ (未命中)
                           ▼
               ┌────────────────────────┐
               │  第一顺位 主门控 (Codiv) │ ──(200 OK)──► 判定完成 (26B 极致置信度)
               │    OpenJev 0.1 (26B)   │
               └───────────┬────────────┘
                           │ (超时 >1.5s 或 HTTP 异常)
                           ▼
               ┌────────────────────────┐
               │  第二顺位 静默热备(Nace)│ ──(200 OK)──► 判定完成 (3B MoE 极速接管)
               │      Drex v2.0 (3B)    │
               └───────────┬────────────┘
                           │ (双机故障)
                           ▼
               ┌────────────────────────┐
               │   全链路 Fail-open 放行 │ ──► 零丢记忆安全底线
               └────────────────────────┘
```

### 节点规格参数
| 节点等级 | 模型标识 | 底座架构 | 服务商 / 端点 | 优势特性 |
|---|---|---|---|---|
| **主门控 (Primary)** | `openjev-latest` | **DiffusionGemma 26B** (NVFP4) | `https://api.codiv.ai/v1/systemone` | 26B 巨无霸大底座，复杂中文长句、混合句事实提炼准确率达 **95%**，极端两极分化绝不和稀泥。 |
| **第一热备 (Backup)** | `drex-v2.0` | **3B MoE** (混合专家激活) | `https://console.nace.ai/v1/systemone` | 响应延迟中位数仅 **503ms**，毫秒级快速接管，保障主链零抖动。 |

## 3. 母语级中英对齐提示词 (Prompt Calibration)

针对跨语言提示词失配问题，`modules/jev_gate.py` 重构为母语级语义提示词：

- **记忆过滤判别 (`should_memorize`)**：
  明确定义“用户个人档案、硬件配置、网络拓扑、否定修正或长期偏好”为 1；“日常闲聊、吐槽发泄或一次性临时杂务”为 0。
- **搜索召回判别 (`needs_memory`)**：
  明确区分“调取私有网络/设备配置、过往历史约束”为 1；“通用编程、常识问答、天气”为 0。
